# ✈️ AI Travel Planner for Students

## 📌 Project Description

AI Travel Planner for Students is a smart web application that helps students plan budget-friendly trips quickly and easily.  

Many travel apps provide general suggestions, but they do not consider student needs such as limited budgets, travel purpose, and practical planning.  

This system uses Generative AI to create personalized travel guides that include destination information, attractions, estimated costs, food options, transportation tips, and safety advice.

The goal of this project is to reduce the time, effort, and cost involved in planning student trips.

---

## 🎯 Objectives

• Provide personalized travel recommendations using AI  
• Help students plan trips within their budget  
• Generate useful travel insights instantly  
• Suggest attractions based on travel purpose  
• Make travel planning simple and time-efficient  

---

## ⚙️ How the System Works

1. User enters:
   - Destination
   - Budget level
   - Travel purpose

2. The system sends the request to the AI API.

3. AI generates a detailed travel guide including:
   - Destination overview
   - Top attractions
   - Budget breakdown
   - Best time to visit
   - Food suggestions
   - Transport tips
   - Safety recommendations

4. The results are displayed on an interactive dashboard.
