## 📌 Project Overview

The AI Travel Planner for Students is a Streamlit web application designed to help students plan safe, budget-friendly trips with minimal effort. The app uses generative AI to create concise travel guides tailored to a student’s destination, budget, and travel purpose.

This project is ideal for recruiters evaluating web applications that combine user experience, API integration, and real-world problem solving.

---

## 🎯 Problem Statement

Students often need travel recommendations that match their budget, interests, and time constraints. Most travel planning tools are generic and do not provide student-specific advice such as low-cost accommodations, food options, transportation tips, and safety guidance.

The AI Travel Planner solves this by generating practical recommendations in a format that is easy to read and use.

---

## ⚙️ Application Flow

1. The user enters a destination in the sidebar.
2. The user selects a budget level: Low, Medium, or High.
3. The user chooses a travel purpose.
4. The app sends the prompt to the OpenRouter AI API.
5. AI returns a travel guide with:
   - Overview
   - Top attractions
   - Budget breakdown
   - Best time to visit
   - Food recommendations
   - Transportation tips
   - Safety advice
6. The app displays the generated travel guide and student travel tips on the dashboard.
